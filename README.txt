UZal and Sonam Choden 3D Memory Gallery — Mobile Optimized

Open index.html in a browser with internet access. Three.js is loaded from a CDN.

Mobile updates: low-power renderer, reduced pixel ratio, disabled real-time shadows on mobile, capped mobile rendering target around 30 FPS, landscape-oriented UI, portrait rotate prompt, and improved small-landscape controls.

Music: see MUSIC_SETUP.txt. Add an authorized music file named music.mp3 beside index.html. The ZIP does not contain the linked YouTube track.

Controls: desktop uses WASD/arrow keys, drag to look, click photos, Space to dance. Mobile uses the left joystick to move, right joystick to look, and tap a frame to open a memory.

Add personal photos using the exact filenames in photos/README.md. Requires internet to load Three.js from its CDN.
