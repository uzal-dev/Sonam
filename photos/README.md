# Your gallery photos

Add your own JPG files here using these exact names:

- `01-the-day-we-met.jpg`
- `02-your-beautiful-smile.jpg`
- `03-little-adventures.jpg`
- `04-favourite-moment.jpg`
- `05-birthday-wish.jpg`
- `06-another-chapter.jpg`

The wall frames load each file by its path. If you want a different filename, change the matching `image: "photos/filename.jpg"` field in the `MEMORIES` array in `index.html`. Filenames are case-sensitive on GitHub Pages.

## Change the birthday wish or stories
Open `index.html` in a code editor. Edit the `MEMORIES` array near the top of the script; the birthday wish is the fifth entry titled `A wish for your birthday`. Change its `title`, `date`, and `text` fields. The website intentionally has no in-game editor.
